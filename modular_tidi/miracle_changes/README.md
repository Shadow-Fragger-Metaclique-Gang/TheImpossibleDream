# Miracle changes

**Tag:** `MIRACLE_CHANGES`

**Created In:** https://github.com/Shadow-Fragger-Metaclique-Gang/TheImpossibleDream/pull/71

**Major changes:**

Changes to which miracles each patron grants.

- `code/patron_miracles.dm`:
    - Lesser Healing is removed from Abyssor, Dendor, Xylix and Malum.
    - Water Healing is removed from Abyssor.
    - The T4 revival miracles are removed from Malum and Xylix.
    - The Painter keeps Lesser Healing.
- `code/bishop_pack.dm`: the Bishop's Sacred Ascendance only offers miracles of Pentacle gods, so the Abyssor, Dendor, Malum and Xylix entries are removed.
